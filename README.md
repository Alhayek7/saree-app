## 💡 المشكلة التي نحلّها

في قطاع غزة، يعاني أصحاب المتاجر والعملاء يومياً من:

- ❌ **لا يوجد نظام موحد** لتوصيل الطرود الخفيفة
- ❌ **أسعار عشوائية** بلا شفافية أو منافسة
- ❌ **لا تتبع حقيقي** — العميل لا يعرف أين طرده
- ❌ **سائقون غير موثوقين** بلا تقييم أو محاسبة
- ❌ **عمولات غير منظمة** تضر الجميع

---

## ✅ الحل: منصة سريع

نظام رقمي متكامل يربط **العملاء** بـ**السائقين** عبر **نظام عطاءات شفاف**، مع تتبع حي وعمولة عادلة — كل ذلك من هاتفك.

```
العميل ينشئ طلب  →  السائقون يتنافسون بأسعارهم  →  العميل يختار الأفضل  →  تتبع حي حتى الباب
```

---

## 👥 الأدوار في المنصة

| الدور | ما يفعله |
|-------|----------|
| 🛍️ **عميل** | ينشئ طلب توصيل ويختار أفضل سائق |
| 🏍️ **سائق** | يتصفح الطلبات ويقدّم عرض سعره |
| 🏪 **وكيل** | يبيع رصيد للسائقين ويتابع عمولاته |
| 🛡️ **أدمن** | يدير المنصة ويراقب جميع العمليات |

## ⭐ الميزات الرئيسية

### 🔥 نظام العطاءات (Bidding)
السائقون يتنافسون على كل طلب — العميل يرى **أرخص 3 عروض** ويختار. الشفافية الكاملة تضمن السعر العادل لكلا الطرفين.

### 📍 تتبع الطلب المباشر
خريطة حية تظهر موقع السائق لحظة بلحظة من لحظة الاستلام حتى التسليم.

### 💰 نظام الرصيد والعمولة
- السائق يبدأ بـ **20 شيكل** رصيد ترحيبي عند التفعيل
- خصم **1 شيكل** فقط لكل طلب مكتمل
- استرداد كامل عند الإلغاء — لا خسارة بلا سبب

### ⚡ تجربة عربية كاملة
واجهة RTL احترافية، خط Cairo، تصميم مخصص للمستخدم العربي.

### 🔔 إشعارات فورية
السائق يُنبَّه فور نشر طلب جديد. العميل يعرف كل تحديث على طرده.

## 🚀 تشغيل المشروع

### المتطلبات
- Node.js v18+
- pnpm
- حساب Supabase (مجاني)
- تطبيق Expo Go على هاتفك

### الخطوات

```bash
# 1. استنساخ المشروع
git clone https://github.com/Alhayek7/Link-Collaboration.git
cd Link-Collaboration

# 2. تثبيت المكتبات
pnpm install

# 3. إعداد متغيرات البيئة
cp .env.example .env
# أضف مفاتيح Supabase و Google Maps

# 4. تشغيل التطبيق
pnpm --filter @workspace/saree run dev
```
